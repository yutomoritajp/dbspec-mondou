# CLAUDE.md

このファイルは、このリポジトリ内のコードを扱う際の、Claude Code（claude.ai/code）向けのガイドラインです。

## 構成

- `docs/` — 仕様書（要件定義 / 基本設計 / 詳細設計）
- Web アプリのコード（実装フェーズで追加予定）

## レビュー規約

このプロジェクトは、要件定義 + 実装をエージェントとユーザーが共同で作成することを目的としている。したがって、以下の手順で開発を進める。

1. ユーザーが要件/実装を行う。
2. ユーザーがエージェントにレビュー依頼を行う。
3. エージェントがレビューし、指摘がなくなるまでこれを繰り返す。

### レビューの注意点

ユーザー主体で実装を進めるため、**レビューで以下の行為は絶対にしないこと**。（ただし、ユーザーからの依頼があった場合はこの限りではない。）

- ファイルの自動作成・編集・削除
- 具体的な修正の提案（文章やコードをそのまま貼り付けて対応することを推奨しない）

このようなレビューが望ましい。

- 問題箇所の指摘
- もっと良くなるためのアドバイス
- インターネットの情報を参照するように提案。（エージェントだけの対話で完結させず、ユーザーに情報を調べさせるように促し一緒に課題に取り組む）
